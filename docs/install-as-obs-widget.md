# Установка MediaTracker и отображение текущего трека в OBS через Mix It Up

## Предварительные требования

- MediaTracker установлен и запущен (см. [README: Установка](../README.md#Установка собранного исполняемого файла)).

## Шаг 1: Настройка OBS

1. Откройте OBS Studio.
2. Добавьте новый источник текста (Text Source) на вашу сцену:
   - Нажмите "+" в окне источников.
   - Выберите "Text (GDI+)" или "Text (FreeType 2)".
   - Назовите источник, например, "Current Track".
   - В настройках текста установите начальный текст, например, "Загрузка...".
   - Нажмите "OK" для сохранения.

## Шаг 2: Настройка Mix It Up

1. Убедитесь, что Mix It Up установлен и подключен к вашему Twitch-каналу и OBS.
2. В Mix It Up откройте раздел "Timers" (Таймеры).
3. Создайте новый таймер:
   - Нажмите "Add Timer".
   - Назовите таймер, например, "Update Current Track".
   - Установите интервал, например, 5 секунд (чтобы обновление было плавным, но не слишком частым).
   - В разделе "Actions" добавьте действие "Web Request":
     - Метод: GET
     - URL: `http://127.0.0.1:5050/`
     - Сохраните ответ в переменную, например, `$currentTrack` (в поле "Store Response In").
   - Добавьте действие "OBS":
     - Выберите "Set Source Text".
     - Выберите источник текста, созданный в OBS ("Current Track").
     - Установите текст: `$currentTrack`
4. Включите таймер.

Теперь текущий трек будет автоматически обновляться в OBS каждые 5 секунд.

## Примечания

- Убедитесь, что MediaTracker запущен перед стримами.
- Если трек не обновляется, проверьте, что эндпоинт доступен и Mix It Up имеет доступ к локальному серверу.
- Для лучшей производительности не устанавливайте интервал таймера меньше 2-3 секунд.
