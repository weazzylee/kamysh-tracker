# Установка MediaTracker и отображение виджета в OBS через Browser Source

## Предварительные требования

- MediaTracker установлен и запущен. Инструкция по установке описана в файле [README.ru.md](../README.ru.md#установка-собранного-исполняемого-файла)

## Шаг 1: Настройка OBS

1. Откройте OBS Studio.
2. Добавьте новый источник Browser Source на вашу сцену:
   - Нажмите "+" в окне источников.
   - Выберите "Browser Source".
   - Назовите источник, например, "Media Widget".
   - В настройках источника:
     - URL: `http://127.0.0.1:5050/widget`
     - Ширина: 400 (или по вашему вкусу)
     - Высота: 180
     - Отметьте "Отключать источник когда невидим" для экономии ресурсов.
     - Отметьте "Обновить браузер, когда сцена становится активной".
   - Нажмите "OK" для сохранения.ss

Виджет автоматически обновляется каждые 5 секунд и меняет стиль в зависимости от приложения (Spotify - зеленый, Yandex Music - синий, другие - серый).

## Примечания

- Убедитесь, что MediaTracker запущен перед стримами.
- Виджет использует прозрачный фон, подходящий для OBS.
- Если виджет не загружается, проверьте, что эндпоинт доступен по адресу http://127.0.0.1:5050/widget
- Для кастомизации создайте файл widget.html рядом .exe файлом. Шаблон для кастомизации - [widget.html](../Resources/widget.html)
