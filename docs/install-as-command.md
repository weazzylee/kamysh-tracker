# Создание чат-команды !трек в Mix It Up для отображения текущего трека

## Предварительные требования

- MediaTracker установлен и запущен (см. [README: Установка](../README.md#Установка собранного исполняемого файла)).
- Mix It Up подключен к вашему Twitch-каналу.

## Шаг 1: Создание чат-команды

1. В Mix It Up откройте раздел "Commands" (Команды).
2. Нажмите "Add Command" для создания новой команды.
3. Настройте команду:
   - **Name**: !трек (или любое другое название, например, !song, !track).
   - **Type**: Chat (если не указано иное).
   - **Command Name**: !трек
   - **Cooldown**: Установите по желанию, например, 10 секунд, чтобы избежать спама.
   - **User Level**: Everyone (или установите ограничения по уровню пользователя).

## Шаг 2: Добавление действия Web Request

1. В разделе "Actions" нажмите "Add Action" и выберите "Web Request".
2. Настройте Web Request:
   - **Method**: GET
   - **URL**: `http://127.0.0.1:5050/`
   - **Store Response In**: `$trackResponse` (или любое имя переменной, например, `$currentTrack`).
   - Остальные поля оставьте по умолчанию (без заголовков, тела запроса и т.д., так как это простой GET-запрос).

## Шаг 3: Добавление ответа в чат

1. Добавьте еще одно действие: "Chat" -> "Send Message".
2. В поле сообщения введите: `Текущий трек: $trackResponse`
   - Здесь `$trackResponse` - это переменная, в которую сохранен ответ от эндпоинта.
   - Вы можете настроить сообщение по своему вкусу, например, добавить эмодзи или дополнительный текст.

## Шаг 4: Сохранение и тестирование

1. Нажмите "Save" для сохранения команды.
2. Включите команду, если есть переключатель.
3. Протестируйте: в чате Twitch введите `!трек`. Mix It Up должен ответить текущим треком в формате "Artist - Title" или "Сейчас ничего не играет".

## Примечания

- Команда будет работать только если MediaTracker запущен и эндпоинт доступен.
- Если ответ не приходит, проверьте логи Mix It Up на ошибки (раздел "Logs").
- Для более сложных команд вы можете добавить условия, например, проверку, играет ли что-то сейчас, используя JSON-эндпоинт (`http://127.0.0.1:5050/json`), но для простого текста достаточно GET /.

## Пример использования

- Зритель пишет: `!трек`
- Бот отвечает: `Текущий трек: The Beatles - Hey Jude`
